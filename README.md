# Sriram portfolio

Run `npm install` followed by `npm run dev` from this directory. Open the local URL printed by Vite.

Use `npm run build` to compile the public site and `npm run preview` to test that build. Both local servers accept contact submissions at `/api/contact` and append them to `.sriram-portfolio/messages.jsonl` in your home directory. Set `PORTFOLIO_INBOX_DIR` to choose another private directory. A static-only deployment needs a server for this endpoint and a fallback to index.html for journal links.

The interactive model is generated by Three.js in `src/lib/three/world.js`. Its pointer and scroll controls live in `src/components/world/WorldCanvas.jsx`.

Move the pointer or tap the arrow keys to orbit the solar system. Scroll to travel through the scene.
